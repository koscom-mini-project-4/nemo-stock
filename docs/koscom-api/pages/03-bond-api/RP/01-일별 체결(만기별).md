[일별체결(만기별)]
● Request
URL

    HOST https://checkapi.koscom.co.kr
    POST /bond/m043/hist_info
  
Parameter
Name	Type	Description	Required
cust_id	String	CHECK 단말 고객번호 10자리 (ex : NS00000001)	O
auth_key	String	API 인증키	O
inst_cd	String	제공처 1자리 (ex : '0')	O
dwm_type	String	주기구분 1자리 (ex : '1')	O
sdate	String	조회 시작 날짜 8자리 (ex: 20220801)	O
edate	String	조회 마지막 날짜 8자리 (ex: 20240801)	O
Data Set
Name	Type	Description	Detail
TRADE_DATE	NUMERIC(8)	일자	
INST_CD	CHAR(1)	제공처	(0:전체, 1:서울외국환중개, 2:한국자금중개, 3:KIDB자금중개)
PERIOD_TYPE	NUMERIC(4)	만기구분	
DWM_TYPE	NUMERIC(2)	주기구분	(1:일,2:주,3:월)
AVG_RATE	NUMERIC(19,3)	평균금리	
AMT	NUMERIC(20)	체결액	

API 테스트 도구

outlink

Example

    python 
    
      import sys, json, requests

      session = requests.Session()
      # SSL 인증 처리 무효화 
      session.verify = False
      host_url = 'https://checkapi.koscom.co.kr'
      api_url = '/bond/m043/hist_info'

      # sample parameter 입니다. 정상 처리 되지 않습니다.
      payload = {"cust_id" : 'NS00000001', "auth_key" : 'Y0va9PYmoKiqWJ7oSVFiyIy2aVHq7lXj', 
        "inst_cd" : '0', "dwm_type" : '1', "sdate" : '20250101', "edate" : '20250401'}
      r = session.post(host_url + api_url, data = payload)

      # 정렬. ensure_ascii = 한글 깨짐 방지. indent = 들여쓰기.
      print(json.dumps(r.json(), ensure_ascii=False, indent=2))

● Response
Name	Value	Description	Detail
success	true	정상	results 참조
results	[Data Set]	-	-
success	false	비정상	message 참조
message	[Error Set]	-	-
Error Message
Error	Error Desc	Description
access_denied	User denied access	고객번호 또는 인증키가 유효하지 않습니다.
jcode_denied	Input code is not found	입력한 종목코드가 유효하지 않습니다.
date_denied	Input date is invalid	입력한 날짜가 유효하지 않습니다.
