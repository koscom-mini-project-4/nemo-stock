[순위정보(공매도-기간합산)]
● Request
URL

    HOST https://checkapi.koscom.co.kr
    POST /stock/m003/rank_short_date
  
Parameter
Name	Type	Description	Required
cust_id	String	CHECK 단말 고객번호 10자리 (ex : NS00000001)	O
auth_key	String	API 인증키	O
criteria_code	String	정렬코드 (공매도수량 : F33094, 공매도금액 : F33095)	O
sdate	String	조회 시작 날짜 8자리 (ex: 20210801)	O
edate	String	조회 마지막 날짜 8자리 (ex: 20220801)	O
-	-	조회기간에 따라서 30초 이상 소요될 수 있습니다.	X
Data Set
Name	Type	Description	Detail
F16013	INT	단축코드

F33095	INT(11)	공매도거래대금	
F15015	INT(11)	거래량
